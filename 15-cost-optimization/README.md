# 15 — Cost Optimization

> Model routing, caching, batching, prompt + output token control

> 📌 **Seeded from AI_Engineer_Interview_Guide.pdf — Q02 (Cost).** See `interview-qa.md`.

**Tier:** 1 — GenAI Core  |  **Interview frequency:** High

## Why this matters for your interviews
Companies want engineers who build without burning the budget. Quantified cost wins are gold in interviews.

## Subtopics checklist
- [ ] Model selection & routing (60-80% savings)
- [ ] Prompt compression
- [ ] Semantic caching + prompt caching
- [ ] Batching & async (50% batch discount)
- [ ] Fine-tuning a small model for efficiency
- [ ] Output length control (max_tokens)
- [ ] Estimating cost before building

## Suggested learning flow
1. Read/skim a primary resource in `resources.md`.
2. Write the core ideas in your own words in `concepts.md`.
3. Distil the must-knows + one-liners into `cheatsheet.md`.
4. Practice out loud from `interview-qa.md` (answer, then check).
5. Build (or map an existing) project in `projects/` and attach a STAR story.
6. Update **Status** below and log a mock answer in `../00-START-HERE/MOCK-INTERVIEW-LOG.md`.

## Interview angles (how they'll probe you)
- How to reduce LLM running cost (guide Q02)
- Estimate a feature's monthly cost
- Cost vs. quality without over-optimizing
