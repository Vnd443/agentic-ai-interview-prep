# 17 — AWS Core

> IAM, S3, EC2, Lambda, Glue, Athena, Lake Formation, CloudWatch

**Tier:** 3 — Backbone  |  **Interview frequency:** Medium

## Why this matters for your interviews
The cloud fundamentals behind your data/AI work. IAM least-privilege and a serverless data pipeline are the must-knows.

## Subtopics checklist
- [ ] IAM: users vs. roles vs. policies, least privilege
- [ ] S3: classes, versioning, lifecycle, partitioning
- [ ] Lambda + event-driven pipelines
- [ ] Glue (ETL) + Athena (serverless SQL) + Data Catalog
- [ ] Lake Formation governance
- [ ] CloudWatch: logs, metrics, alarms
- [ ] Storage & data stores: RDS PostgreSQL (relational) + DynamoDB (key-value) for app/agent state

## Suggested learning flow
1. Read/skim a primary resource in `resources.md`.
2. Write the core ideas in your own words in `concepts.md`.
3. Distil the must-knows + one-liners into `cheatsheet.md`.
4. Practice out loud from `interview-qa.md` (answer, then check).
5. Build (or map an existing) project in `projects/` and attach a STAR story.
6. Update **Status** below and log a mock answer in `../00-START-HERE/MOCK-INTERVIEW-LOG.md`.

## Interview angles (how they'll probe you)
- IAM roles vs. users vs. policies + least privilege
- Walk through a serverless data pipeline
- How you monitor/debug an AWS workload
