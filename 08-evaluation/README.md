# 08 — Evaluation

> LLM-as-judge, RAGAS, task metrics, regression + adversarial testing

> 📌 **Seeded from AI_Engineer_Interview_Guide.pdf — Q06 (Evaluation).** See `interview-qa.md`.

**Tier:** 1 — GenAI Core  |  **Interview frequency:** High

## Why this matters for your interviews
If you can't measure quality you can't ship responsibly. Evaluation is what separates a demo from a production system.

## Subtopics checklist
- [ ] Task metrics (F1, ROUGE, BLEU, BERTScore) aligned to goal
- [ ] LLM-as-judge + rubrics to cut variance
- [ ] Human eval / A/B / annotation pipelines
- [ ] RAGAS: faithfulness, relevance, context precision/recall
- [ ] Adversarial / red-team testing
- [ ] Regression testing + eval in CI

## Suggested learning flow
1. Read/skim a primary resource in `resources.md`.

## Interview angles (how they'll probe you)
- How do you evaluate LLM output quality (guide Q06)
- How do you evaluate a RAG system specifically
- Eval in CI to prevent regressions
