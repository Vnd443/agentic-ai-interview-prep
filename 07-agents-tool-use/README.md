# 07 — Agents & Tool Use

> LLM-in-a-loop, ReAct, plan-execute, orchestration, error handling

> 📌 **Seeded from AI_Engineer_Interview_Guide.pdf — Q08 (Agents).** See `interview-qa.md`.

**Tier:** 1 — GenAI Core (HEADLINE)  |  **Interview frequency:** Very High

## Why this matters for your interviews
The biggest trend in applied AI and a headline of your resume. Expect deep probing on orchestration, reliability, and guardrails.

## Subtopics checklist
- [ ] Agent loop: observe -> think -> act
- [ ] Tool definition: schemas as API docs
- [ ] Orchestration: ReAct, Plan-Execute, Map-Reduce
- [ ] Error handling: retries, fallbacks, max-iteration limits
- [ ] Guardrails: permissions, HITL, sandboxing
- [ ] Chain vs. agent vs. workflow (determinism as a feature)
- [ ] Evaluating & tracing agents
- [ ] Tool design principles: clear names/descriptions, right granularity, helpful error messages
- [ ] ReAct in depth (reason ↔ act ↔ observe loop)
- [ ] Computer use & app SDKs — agents that drive a browser/GUI ("eyes and a mouse")

## Suggested learning flow
1. Read/skim a primary resource in `resources.md`.
