# 11 — LangChain & LangGraph

> Chains, agents, graphs, memory, tool integration

**Tier:** 2 — Frameworks  |  **Interview frequency:** Medium

## Why this matters for your interviews
The framework layer for your GenAI work. Interviewers want to know you can use it AND when to drop it.

## Subtopics checklist
- [ ] LangChain: chains, prompts, retrievers, integrations
- [ ] LangGraph: stateful graphs, cycles, conditional edges
- [ ] Framework vs. plain SDK — least abstraction that works
- [ ] Memory: short-term buffer vs. long-term store
- [ ] Checkpointing & human-in-the-loop nodes

## Suggested learning flow
1. Read/skim a primary resource in `resources.md`.
2. Write the core ideas in your own words in `concepts.md`.
3. Distil the must-knows + one-liners into `cheatsheet.md`.
4. Practice out loud from `interview-qa.md` (answer, then check).
5. Build (or map an existing) project in `projects/` and attach a STAR story.
6. Update **Status** below and log a mock answer in `../00-START-HERE/MOCK-INTERVIEW-LOG.md`.

## Interview angles (how they'll probe you)
- LangChain vs. LangGraph vs. plain API
- How LangGraph models an agent (and why a graph)
- Handling memory
